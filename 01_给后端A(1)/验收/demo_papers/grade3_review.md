## 1. [single_choice] 色彩搭配 / 邻近色 · 难度1

关于邻近色的描述，以下哪个说法是正确的？

A.邻近色是指冷暖色调 B.邻近色是位于色轮上的相邻颜色 C.邻近色指同一色调不同明度的颜色 D.邻近色与对比色相同，都是两种颜色

**答案：** B

**解析：** 邻近色是指色轮上相邻的颜色，它们在视觉上更接近，给人以和谐的感觉。选项A错误，因为邻近色并非冷暖色调；选项C描述的是类似色；选项D错误，对比色与邻近色是不同的概念。

## 2. [single_choice] 造型表现 / 线描 · 难度2

下面哪个图形是通过线条画出来的（ ）。

A.素描 B.水彩 C.水粉 D.蜡笔

**答案：** A

**解析：** 素描是通过线条画出来的绘画形式；水彩、水粉和蜡笔是颜料绘画形式，不是线条画。

## 3. [single_choice] 色彩搭配 / 邻近色 · 难度1

在色彩搭配中，相邻的色彩被称为邻近色。下列哪一组是邻近色？

A.红色和黄色 B.蓝色和绿色 C.橙色和紫色 D.黄色和绿色

**答案：** D

**解析：** 邻近色是指在色轮上彼此相邻的颜色，它们之间的对比度较低，给人一种和谐的感觉。黄色和绿色在色轮上是相邻的色彩，因此选项D是正确的。

## 4. [single_choice] 色彩搭配 / 色彩搭配 · 难度1

在色彩搭配中，对比色指的是（ ）。

A.相同色调的两种颜色 B.不同色调的两种颜色 C.互补色的两种颜色 D.同一色系的两种颜色

**答案：** C

**解析：** 对比色是指色彩相隔180度的色轮位置的颜色，它们之间的对比强烈。选项A和D属于同一色系，但不是对比色。选项B则是错误概念，没有提到‘不同色调’这一要点。

## 5. [single_choice] 构图入门 / 主体突出 · 难度1

下列哪个图形更适合做画中的主体？（ ）

A.背景色块 B.色彩对比明显的图形 C.面积大的图形 D.形状圆润的图形

**答案：** B

**解析：** 主体应该吸引观众的注意力，色彩对比明显的图形更容易突出，而背景色块、面积大的图形以及形状圆润的图形通常作为背景使用。

## 13. [fill_blank] 色彩搭配 / 邻近色 · 难度1

邻近色是______相邻的颜色，它们在色轮上靠近且距离较近。

**答案：** ['青色']

**解析：** 邻近色是指在同一色轮上相邻的颜色，它们之间距离较近，青色是紫色与蓝色之间的过渡色，因此最符合题意。

## 14. [fill_blank] 色彩搭配 / 色彩搭配 · 难度1

色彩搭配的基本原则包括对比色、____和____。

**答案：** ['调和色', '邻近色']

**解析：** 调和色是指通过色相、明度和纯度的不同变化来达到色彩和谐的效果。邻近色则是指在色轮上相邻的颜色。对比色则指的是色相上相对的颜色，能够产生强烈的视觉效果。在这道题中，需要选择两个正确的基本原则。

## 15. [short_answer] 造型表现 / 细节观察 · 难度1

描述一幅作品，指出它采用了哪种构图方法，并解释其特点。

**答案：** 这幅作品采用了对称构图，它具有画面左右或上下对应的特点，给人一种视觉上的稳定和庄重感；但若处理不当可能会显得过于呆板，通常通过局部的变化来增加画面的生动性。

**解析：** 对称构图的特点包括画面左右或上下对应，给人以视觉上的稳定与庄重；其缺点是容易显得呆板，需通过局部变化增加画面的生动性。答对对称构图及其特点即可得满分。
