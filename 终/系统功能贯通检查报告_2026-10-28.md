| 横切关注点 | 角色权限、数据范围、通知、审计日志、文件归属、异步任务、演示数据 |

### 2.2 检查方法

1. **接口双向对照**：把后端 URL 与前端 API 方法逐一比对，标记“只在一端存在”的能力。
2. **页面—接口—服务追踪**：对每个页面按钮，追到 API、视图、服务、模型和权限判断，确认按钮可见性与后端允许的角色一致。
3. **角色闭环走查**：分别以学生、教师、学校管理员、区县/市/省管理员、题库管理员身份走完整业务链。
4. **生命周期走查**：账号创建 → 班级归属 → 出题 → 组卷 → 审核 → 发布 → 作答 → 交卷 → 评分 → 出分 → 统计/证书/报告 → 通知/审计。
5. **数据口径检查**：随机练习与正式测评在成绩、统计、证书、报告、列表中是否被正确区分。
6. **异常路径检查**：跨校申请、越权操作、异步导入、重复提交、自动交卷、待审核试卷修改/发布。

### 2.3 判定标准

- **断链**：前端有入口但后端无实现，或后端有实现但前端无入口且该能力属于核心业务。
- **越权/错权**：页面展示了当前角色无法执行的操作，或后端允许了超出数据范围的操作。
- **口径错误**：同一业务数据在不同页面使用不同筛选条件，导致数量、分数、排名不一致。
- **状态断点**：业务状态机缺少必要流转（如审核未通过仍能发布、评分完成不通知）。
- **产品缺口**：能力存在但未设计 UI，或策略尚未确定；单列，不当作缺陷强行修改。

## 四、按真实使用顺序走查

### 4.1 登录与账号

**正常路径**：账号密码登录 → 后端按账号角色返回 token 与用户信息 → 前端按角色进入默认页。登录页提供各端测试账号快捷填入。

**关联影响**：账号的 `org` 决定数据范围；学生 `StudentProfile.classroom` 决定班级与测评；教师 `TeacherProfile.subject` 与 `ClassTeacher` 决定任教范围。

**本轮发现并修复**：

- 区县/市州管理员创建下属组织账号时缺少可选组织下拉数据源 → 新增 `GET /accounts/org-options`，前端账号编辑按层级联动加载。
- 市州管理员创建“市直属学校”时未传 `districtId` 会被拒绝 → 后端在操作者为市州管理员且未指定区县时，直接以市州组织为父级创建学校。
- 省级管理员页面出现“学生导入”入口，但后端只允许学校管理员导入 → 前端按角色隐藏导入按钮与班级选择器。

### 4.2 班级与师生关系

**正常路径**：学校管理员建班 → 教师申请加入/被分配 → 班主任审核 → 学生申请加入 → 教师/班主任审核 → 学生进入班级。

**关联影响**：班级归属同时影响测评目标、教师数据范围、成绩班级维度、统计班级维度、证书班级信息。

**本轮发现并修复**：

- 班主任（`Class.head_teacher`）没有 `ClassTeacher` 行时，其班级不在 `DataScope` 内，导致看不到本班试卷、测评、评分、成绩、统计、证书、成长数据 → `DataScope` 的教师班级与学校集合改为“科任班级 ∪ 班主任班级”。
- 学生/教师可申请加入外校班级，审核也可通过 → 增加“申请人学校必须与班级学校一致”的校验（申请与审核两处）。
- 班级申请提交后无任何通知，只能靠页面轮询 → 提交时通知班主任与科任教师；审核通过/驳回时通知申请人。
- 班级学生批量导入生成随机密码但不返回，教师无法告知学生 → 导入结果新增 `credentials`（学号、姓名、账号、初始密码），前端导入后弹窗展示并支持下载 CSV；同时支持表格中的“初始密码”列。

### 4.3 题库与课程

**正常路径**：教师创建试题（单选/多选/判断/填空/简答/图片/音频/听力）→ 上传资源 → 提交审核 → 题库管理员审核 → 通过后可用于组卷。

**关联影响**：题目创建人决定教师可编辑范围；题目状态决定能否组卷；题目资源被试卷引用时禁止删除。

**本轮发现并修复**：

- 教师端试题页面沿用了题库管理员视图，教师看到“审核/发布”等无权按钮 → 按角色拆分：教师仅能编辑/提交/删除本人试题并上传资源，题库管理员才可审核。
- 教师无法把被驳回的试题重新提交审核 → 前端增加“提交审核”，对接已有 `POST /questions/{id}/submit-review`。
- 试题审核结果没有通知创建人 → 审核信号接入通知中心，通过/驳回均通知出题教师，驳回带审核意见。
- 题库管理员原先可删除任意业务文件 → 收紧为仅可删除题目图片/音频；学校及上级管理员仅可删除本校范围内的文件。

### 4.4 组卷、审核与发布

**正常路径**：教师手动/自动组卷（自动组卷固定 100 分）→ 保存草稿 → 提交审核 → 题库管理员审核 → 通过后发布测评。

**关联影响**：试卷审核状态直接影响测评发布；试卷内容影响作答快照、评分标准、成绩满分；测评目标范围决定参与学生与参与人数。

**本轮发现并修复**：

- 试卷审核通过/驳回后仍可修改，审核中的试卷也可改，导致“审核过的内容”和“实际发布的内容”不一致 → `pending` 禁止修改，`approved` 禁止修改（需复制为新卷）；`rejected` 可修改后重新提交。
- 未通过审核或仍在审核中的试卷可被发布 → 发布时增加审核状态校验。
- 教师可对非本人试卷执行操作但后端 403 → 前端按“创建人/非教师”收口操作菜单。
- 组卷/审核列表混入学生随机练习卷 → 教师与管理端试卷列表默认只返回正式卷；学生练习卷不进入组卷与审核。
- 试卷审核详情缺少选项、资源、解析、评分细则、评分方式 → 详情接口补齐字段，审核人可看到完整题目信息。

### 4.5 学生作答与交卷

**正常路径**：学生进入测评 → 开始答卷 → 自动保存/保存并退出 → 上传图片或录音 → 交卷（手动或倒计时自动）。

**关联影响**：答卷快照固定题目与分值；上传文件归属学生与答卷；交卷触发自动判分并决定是否进入人工评分。

**本轮发现并修复**：

- 倒计时自动交卷发送 `submitType: "auto"`，后端只接受 `"manual"`，自动交卷 400 → 后端接受 `auto`，并保留手动默认值。
- 学生随机练习卷对同班同学可见/可作答 → 练习卷仅发布者本人可见、可进入。
- 音乐实践题浏览器录音已支持 WEBM/OGG 上传，后端文件魔数与分类校验已覆盖。

### 4.6 评分、补录、导入与重新判分

**正常路径**：客观题自动判分；含简答/实践题的交卷进入教师评分队列；教师逐题打分并终评 → 生成/更新成绩 → 通知学生。支持线下补录、成绩导入与重新判分。

**关联影响**：成绩是统计、排名、证书、学习报告、错题与通知的共同数据源；成绩来源（在线/补录/导入）决定能否重新判分。

**本轮发现并修复**：

- 成绩导入超过阈值转为后台任务，但前端只能拿到 `queued`，无法获知结果 → 新增 `GET /scores/imports/{taskId}`，前端每 2 秒轮询并在弹窗展示进度/结果。
- 补录与导入可选中随机练习卷，导致练习成绩进入正式成绩 → 成绩管理只列出正式测评，后端补录/导入拒绝练习卷。
- 正式成绩列表、统计、学生成绩页混入随机练习 → 成绩列表默认正式卷并返回 `paperType`；统计只算正式卷；学生成绩页过滤练习。
- 后端已有重新判分接口但前端无入口 → 成绩管理新增“重新判分”，仅在线作答成绩可用，要求填写原因，写审计日志。
- 补录/导入成绩没有答卷，重新判分会 409 → 前端按 `attemptId` 禁用按钮，接口错误信息明确提示重新补录。
- 终评后学生不知道成绩已发布 → 终评事务完成后发送系统通知，跳转“我的成绩”。
- 测评结果缺少等级字段，学生端只能看分数 → 答卷结果补齐 `level`。
- 教师导入超过 500 行转异步，前端提示“成功 0 条” → 新增账号导入任务查询，前端轮询并在完成后刷新。

### 4.7 成绩、统计与排名

**正常路径**：按角色数据范围查看成绩 → 按班级/学校/区县/市州维度统计 → 导出 CSV。

**关联影响**：统计口径必须与成绩管理一致；排名基于成绩重算；导出内容随筛选条件变化。

**本轮发现并修复**：

- 统计口径未排除随机练习，练习卷拉低/扰动正式统计 → `_assessments_qs` 统一只取正式测评。
- 成绩列表默认包含练习卷 → 默认正式卷，仅在明确传 `paperType=practice/all` 时切换。
- 统计页“概览”由前端用列表汇总，后端 `/scores/statistics` 概览接口未被使用（保留，见第七节）。

### 4.8 证书

**正常路径**：教师/管理员按测评生成证书 → 学生在“我的证书”查看/下载。

**关联影响**：证书依赖已出分成绩；重判后证书内容不会自动刷新（见第七节）。

### 4.9 错题、学情报告与成长

**正常路径**：学生查看错题、重做错题；系统按正式成绩生成学情报告；学生查看成绩趋势。

**关联影响**：报告依赖正式成绩；新成绩发布后报告应更新。

**本轮发现并修复**：

- 学情报告只在首次生成，新成绩后长期不更新 → 查询时若最新正式成绩晚于报告生成时间则自动重建。
- 学生成绩页的“趋势”只使用本人成绩列表，练习卷已过滤。
- 成长曲线接口保留但学生端使用成绩页趋势图与学习报告（见第七节）。

### 4.10 通知、审计与文件

**正常路径**：评分完成、班级申请、试题审核等事件写入通知；关键操作写入审计日志；文件按归属与分类受控。

**关联影响**：通知跳转路径必须与前端路由一致；文件删除必须受题目引用与数据范围约束。

**本轮发现并修复**：

- 评分完成、班级申请、试题审核三类事件无通知 → 已接入。
- 文件删除权限过宽（题库管理员可删任意文件、管理员可删范围外文件）→ 已收紧。
- 教师“学习材料”列表可看到非任教班级学生作品 → 文件列表按教师班级范围过滤。

## 五、前后端功能对照

### 5.1 前端有、后端无

**结论：无。** 检查中发现的 2 处均已在后端补齐：

### 8.3 手工回归建议（按顺序）

1. 学校管理员登录 → 创建班级 → 创建教师/学生账号 → 分配班级。
2. 教师登录 → 申请加入班级 → 班主任/管理员审核 → 查看通知。

5. 含简答题：学生交卷后无最终成绩 → 教师评分终评 → 学生收到通知 → 成绩页出现成绩。
6. 教师补录/导入成绩 → 成绩列表与统计只含正式测评 → 导入进度可查。
7. 学生对同一测评发起随机练习 → 同班其他学生不可见 → 学生成绩页不显示练习成绩。
8. 教师重新判分在线成绩 → 审计日志有记录；补录成绩按钮禁用。
9. 教师导入班级学生 → 弹窗展示初始账号/密码并可下载。
10. 学生查看学习报告 → 完成新测评并出分后报告自动更新。
