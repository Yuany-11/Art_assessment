# E3 档位映射规则（待确认）

## 目标

E3 序数/CORAL 头要回答的是“等级判得准不准”，不是“分数回归 MAE 低不低”。先把 APDD 的 Total score 到 90/75/60 的映射固定下来，再训练。

## 规则

APDD 的 `Total aesthetic score` 是 0–100 的百分制，直接按现有等级线切：

| 档位 | APDD Total score |
|---|---|
| excellent 优秀 | `>= 90` |
| good 良好 | `[75, 90)` |
| pass 合格 | `[60, 75)` |
| fail 不合格 | `< 60` |

模型侧：

- **主口径**：模型四维原始输出取平均 = total，再按 90/75/60 切档。
- **对照口径**：APDD 四维标签也取平均（构图、色彩、造型、创意，各 0–100），按同一等级线切；它和 `Total aesthetic score` 的相关系数约 **0.971**，均值差约 **-2.49**。
- **不用校准后的分数做 E3 主验收**：v3.1 校准是显示口径，会把分数整体抬高，和 APDD 原始 Total 不可直接比。校准后的档位只作为产品侧参考。

## 数据问题

APDD 10,023 张里：

- `Total aesthetic score >= 90` 只有 **27 张（0.27%）**
- `>= 75` 2,902 张
- `>= 60` 6,884 张

四维各自 `>=90` 也只有 2–11 张。也就是说：**excellent 档在 APDD 上无法做有统计意义的验收**，测试集 1,923 张里只会更少。

## 建议验收口径

- 主报：**fail / pass / good 三档准确率 + 总体档位准确率 + 四维 MAE**
- 90 线只报“预测为 excellent 的数量”和混淆矩阵，不单独作为通过/不通过条件
- 如果必须验收 excellent，需要 KidsArtBench 或校内高分样本，APDD 不够
