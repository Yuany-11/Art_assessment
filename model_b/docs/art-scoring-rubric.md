- 版本：v1.0
- 日期：2026-10-23
- 适用：`POST /api/v1/ai/art/score` 的分数定义、标注规范、训练标签来源

## 1. 依据说明

本表**不是**教育部发布的原始表格，而是根据公开发布的官方评价文件归纳出的可执行评分表。**官方文件没有全国统一的四维数值权重**；四个维度的名称来自课程标准与各地美术考试评分口径，各维 25 分的权重由本项目确定，可通过接口 `rubric` 字段调整。

### 1.2 官方评分与等级（2015 年办法原文）

| 一级指标 | 二级指标 | 分值 |
|---|---|---|
| 基础指标 | 课程学习 | 25 |
| 基础指标 | 课外活动 | 15 |
| 学业指标 | 基础知识 | 25 |
| 学业指标 | 基本技能 | 25 |
| 发展指标 | 校外学习 | 10 |
| 发展指标 | 艺术特长（加分） | 10 |

等级线：**90 分以上优秀、75–89 良好、60–74 合格、60 分以下不合格**。本表第 2 节的等级线与此一致。

### 1.3 四维从哪来

官方文件只给评价方向和等级线，没有"构图 25 分、色彩 25 分"这种拆分。四维是本项目在官方口径基础上落地的方案：

- **构图、色彩、造型**：课程标准中的"艺术表现"与各地美术考试评分细则共同指向；
- **创意**：对应课程标准"创意实践"与各地"构思新颖、想象力丰富"的描述。

因此对外说明时必须写清楚：**分档描述和等级线有官方依据，四维权重是项目约定**，可按当地当年文件调整。落地时若当地文件更新，以当地文件为准。

## 2. 总分与等级

- 每维 0–100 分，保留 1 位小数；
- 总分 = Σ(维度分 × 权重) / 100，保留 2 位小数；
- 默认权重：构图 25、色彩 25、造型 25、创意 25；
- 等级：`excellent ≥ 90`、`good ≥ 75`、`pass ≥ 60`、`fail < 60`。

## 3. 分档描述

### 3.1 构图 composition（25 分）

| 档位 | 分值 | 描述 |
|---|---|---|
| 优 | 90–100 | 主体突出，位置符合视觉重心或有意打破；疏密有致，画面平衡；留白得当；边缘不拥挤 |
| 良 | 75–89 | 主体明确，整体平衡；局部略空或略挤，但不影响阅读 |
| 中 | 60–74 | 能看出主体，但重心偏移明显，或四周元素争抢视线 |
| 差 | < 60 | 无明确主体，画面失衡或元素堆叠在边角；构图基本失控 |

### 3.2 色彩 color（25 分）

| 档位 | 分值 | 描述 |
|---|---|---|
| 优 | 90–100 | 色彩关系明确（冷暖/互补/同类色），层次丰富，主色调统一且有变化 |
| 良 | 75–89 | 色彩较鲜明，冷暖关系基本协调，局部略脏或略平 |
| 中 | 60–74 | 用色单一或杂乱，缺少层次；明度对比不足 |
| 差 | < 60 | 色彩脏、灰、糊，或大面积平涂无变化；黑白作品按造型/构图评价，色彩维度按“该作品类型下的完成度”给分并注明 |

### 3.3 造型 modeling（25 分）

| 档位 | 分值 | 描述 |
|---|---|---|
| 优 | 90–100 | 形体准确，比例恰当，透视/结构合理；线条流畅，明暗层次分明，细节清楚 |
| 良 | 75–89 | 形体基本准确，局部比例或透视有小偏差；细节尚可 |
| 中 | 60–74 | 形体可辨认但变形明显；线条僵硬或细节缺失 |
| 差 | < 60 | 形体难以辨认，结构混乱；画面模糊或未完成 |

### 3.4 创意 creativity（25 分）

| 档位 | 分值 | 描述 |
|---|---|---|
| 优 | 90–100 | 构思新颖，有个人表达；主题明确且有独特处理；画面有记忆点 |
| 良 | 75–89 | 有一定想法，主题较清楚；构成方式较常规但完整 |
| 中 | 60–74 | 以临摹/套模板为主，个人表达弱 |
| 差 | < 60 | 无主题，内容拼凑或空白 |

> 创意维度只能由画面结构、色彩多样性、非对称性等间接指标估计，**不等同于教师判断**，报告中必须注明。

## 4. 与图像指标的可计算对应（用于基线/训练特征）

| 维度 | 客观指标 |
|---|---|
| 构图 | 三分法边缘能量分布、重心偏移、左右/上下平衡、对称性、留白比例 |
| 色彩 | 平均饱和度、明度对比度、色彩丰富度、色相分布熵 |
| 造型 | 拉普拉斯方差（清晰度）、边缘密度、细节丰富度 |
| 创意 | 色相多样性、结构复杂度、不对称性 |

训练时这些指标可作为特征，也可作为模型输出的辅助校验（模型分数与指标严重矛盾时报警）。

## 5. 标注规范（给人工打分用）

1. 每张作品由 2–3 人独立打分，取平均值；
2. 评分人之间单维分差 > 20 分的样本，重新复核或剔除；
3. 标注文件 `labels.csv`：`image_path,composition,color,modeling,creativity`；
4. 每个维度至少覆盖 60 分以下、60–74、75–89、90 以上四个区间，避免数据偏斜；
5. 作品类型（paint/sketch/design/craft）单独一列，用于分类型评估。
