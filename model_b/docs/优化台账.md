- **模型优化** = 改了训练参数/权重，模型能力本身变化。

## 三、结论（汇报口径）

1. **精度提升来自 10-27 的 v3.0 训练**：7.21 vs 常数基线 10.94，这是唯一可称为“模型优化”的成果。
2. **10-28 的 v3.1 是输出优化**：分数分布和稳定性变好，模型能力没变，不能写成“模型变准了”。
3. **10-28 的排序头没有成功**，现有模型未动。
4. 要再提升精度，只有一条路：拿到新的真值（人工 pairwise 或专家评分数据）后重新训练；否则所有改动都只是后处理。
5. 10-29 的人工排序头在**儿童画域内**有效（交叉验证 71.5%），但与专家审美冲突（APDD 高>低只有 19.2%），说明它学的是“儿童画偏好/整洁度”，不是通用质量。只能做学生域实验，不能替换 M0。

## 四、以后验证“是否真提升”的指标

- 新留出集上的 MAE（不是训练集/旧测试集）。
- 成对排序正确率：大师 vs 学生、高分 vs 低分。
- 五档一致率：优秀/良好/合格/不合格与真值是否同档。
- 同图重复评测波动。
- 必须写明测试集来源；没有新真值就不能声称提升。
