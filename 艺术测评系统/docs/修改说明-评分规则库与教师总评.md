## 1. 变更概览

本次在 v2.0 基础上新增两块能力：

1. **模型评分规则库**：把音乐/美术模型输出的 0-1 能力指标，按“社会艺术水平考级”1-10 级通用基线换算成百分制分数。规则以 YAML 维护，后端负责锚点插值、加权、封顶、等级判定和人工复核标记，避免“模型直接给分、口径无法追溯”。
2. **教师总评规则**：教师按班级/学科/学期配置“平时测试、正式测评、证书”三项占比，系统按规则计算全班学期总评，输出分项得分、贡献、等级与汇总统计。

两块的共同目标是：**分数由可配置、可追溯的规则算出，模型与证书只提供证据或原始值**。

| 能力 | v2.0 原状 | 本次新增后 |
| --- | --- | --- |
| 音乐/美术模型评分 | 模型返回的 `score` 直接作为建议分 | 模型返回 0-1 `metrics`，后端按考级规则重算；仍保留人工确认 |
| 评分口径 | 固定在代码里，无法按学科/类别/级别调整 | 规则库 YAML 可配置，按学科/类别/1-10 级组织，改文件即生效 |
| 学期总评 | 无统一总评口径，需线下计算 | 教师按班级/学科/学期配置平时、正式、证书占比，接口实时计算 |
| 分数追溯 | 模型分与人工分 | 结果携带 `ruleId/ruleVersion/capsApplied/分项贡献`，可回溯口径 |

## 4. 模型评分规则库

### 4.1 规则文件结构

```yaml
meta:
  id: music
  version: "1.0.0"
  standard: 社会艺术水平考级（通用基线）
  defaultBandCutoffs: {excellent: 0.90, good: 0.80, pass: 0.60}
levels:
  "5":
    label: 五级
    stage: 中级
    expectation: 该级别的能力描述
    bandCutoffs: {excellent: 0.90, good: 0.80, pass: 0.60}
anchorProfiles:
  standard: [[0, 0], [0.40, 0.30], [0.60, 0.55], ...]
categories:
  vocal:
    name: 声乐
    dimensions:
      - key: pitch
        name: 音准
        weight: 0.25
        metric: pitchAccuracy
        anchor: strict
        required: true
    caps:
      - metric: pitchAccuracy
        op: lt
        value: 0.50
        maxRatio: 0.50
        reason: 音准未达到基本要求，总分封顶 50%。
```

加载时会校验：

- `meta.id` 与文件名一致；`version` 必填；`levels` 必须且只能包含 1-10 级。
- 等级线满足 `excellent >= good >= pass`，且都在 0-1。
- 同一类别内维度权重之和必须为 1；指标名不得重复。
- 锚点横坐标严格递增；封顶引用的指标必须存在。

### 4.2 类别与维度权重

**音乐（`music.yaml`）**

| 类别 | 维度（权重） | 硬性封顶 |
| --- | --- | --- |
| `vocal` 声乐 | 音准 .25、节奏 .20、音色 .20、咬字 .15、表现 .20 | 音准 < .50 → 50%；节奏 < .50 → 60% |
| `instrumental` 器乐 | 音准 .25、节奏 .20、技术 .20、音色 .15、表现 .20 | 音准 < .50 → 50%；节奏 < .50 → 60%；技术 < .40 → 60% |
| `solfege` 视唱练耳 | 音准 .30、节奏 .25、视谱 .20、调性 .15、表现 .10 | 音准 < .50 → 50%；视谱 < .40 → 60% |
| `theory` 乐理 | 音高谱号 .25、节奏节拍 .25、术语 .20、调式 .20、综合 .10 | 无；`modelScored=false`，以客观题自动判分为主 |

**美术（`art.yaml`）**

| 类别 | 维度（权重） | 硬性封顶 |
| --- | --- | --- |
| `sketch` 素描 | 构图 .15、比例透视 .25、结构 .25、明暗 .20、技法 .15 | 比例透视 < .30 → 55%；构图 < .30 → 60% |
| `color` 色彩 | 构图 .15、色彩关系 .25、色调 .20、塑造 .20、完整 .20 | 色彩关系 < .30 → 55%；完整度 < .30 → 50% |
| `quick_sketch` 速写 | 比例动态 .30、线条 .20、结构 .20、表现 .15、完整 .15 | 比例动态 < .30 → 55%；完整度 < .30 → 50% |
| `calligraphy` 书法 | 笔法 .25、结体 .25、章法 .20、墨法 .15、神采 .15 | 结体 < .30 → 55%；笔法 < .30 → 60% |
| `children` 儿童画 | 创意 .30、构图 .20、色彩 .20、造型 .15、完整 .15 | 完整度 < .30 → 50% |

音乐、美术共用同一套 1-10 级等级线（`pass` 均为 0.60）：

| 级别 | 阶段 | 优秀线 | 良好线 |
| --- | --- | --- | --- |
| 1 | 启蒙 | 0.85 | 0.72 |
| 2 | 基础 | 0.86 | 0.74 |
| 3 | 初级 | 0.88 | 0.76 |
| 4 | 初级 | 0.88 | 0.78 |
| 5 | 中级 | 0.90 | 0.80 |
| 6 | 中级 | 0.90 | 0.80 |
| 7 | 高级 | 0.92 | 0.82 |
| 8 | 高级 | 0.92 | 0.83 |
| 9 | 专业 | 0.94 | 0.85 |
| 10 | 专业 | 0.94 | 0.86 |
| 未指定 | 通用 | 0.90 | 0.80 |

锚点（指标值 → 得分比例，分段线性插值）：

| 锚点 | 0.00 | 0.40 | 0.60 | 0.75 | 0.85 | 0.95 | 1.00 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `standard` | 0.00 | 0.30 | 0.55 | 0.74 | 0.86 | 0.96 | 1.00 |
| `strict` | 0.00 | 0.25 | 0.50 | 0.70 | 0.83 | 0.94 | 1.00 |
| `lenient` | 0.00 | 0.38 | 0.62 | 0.78 | 0.88 | 0.97 | 1.00 |

### 4.4 计分流程

1. 校验每个指标为 0-1 数字；未知指标忽略并写入 `warnings`。
2. 按维度的 `anchor` 把指标值插值成得分比例。
3. 按维度 `weight` 加权汇总，得到总分比例。
4. 依次应用 `caps`；命中则压低总分并写入 `capsApplied`。
5. 总分 = 总分比例 × `maxScore`，按级别 `bandCutoffs` 判定优秀/良好/合格/不合格。
6. 必填指标缺失时 `totalScore=null`、`needsManualReview=true`；置信度 < 0.60 同样转人工复核。
7. 按维度上声明的 `competency` 汇总核心素养维度的得分比例。

### 4.6 与 AI 适配层的集成

| 位置 | 行为 |
| --- | --- |
| `analyze_answer` | 音乐/美术的音频、图片上传题，在请求体中附加 `scoringRules`（含类别维度、级别、锚点、封顶、输出 schema） |
| `_rule_target` | 优先使用题目快照 `ruleContext`，其次调用参数；缺类别时按题干关键词推断，仍无法判断则下发整科规则由模型选择 |
| `_evaluate_rules` | 模型返回非空 `metrics` 且类别有效时，调用规则库重算；模型返回的合法 `category` / `level` 优先补位 |
| `reevaluate_attempt` | 用规则算出的 `totalScore` 覆盖模型原始分，并把规则摘要（`ruleId/version/totalScore/bandLabel/capsApplied/warnings/needsManualReview`）追加到 `ai_analysis` |

关键约定：

```json
{
  "category": "vocal",
  "level": 5,
  "confidence": 0.86,
  "metrics": {"pitchAccuracy": 0.92, "rhythmAccuracy": 0.88},
  "analysis": "音准稳定，乐句处理完整。",
  "evidence": {}
}
```

- 模型只返回 `score`、没有 `metrics` 时，保持原行为，以模型分为建议值。
- 规则计算失败（类别不存在、指标越界等）时记录 warning 并回退模型分，不阻断评分。
- 题目可在 `answer._ruleContext` 中声明 `{"category": "vocal", "level": 5}`；组卷、发布测评、开始答题的快照会自动带出 `ruleContext`。

## 5. 教师总评规则

### 5.1 需求映射

| 教师侧诉求 | 实现方式 |
| --- | --- |
| 设置平时测试占比 | `usualWeight` |
| 设置正式测评占比 | `formalWeight` |
| 设置证书占比 | `certificateWeight` |
| 按班级/学科/学期区分口径 | `classId + subject + term` |
| 按规则得到学生总评 | `GET /total-score-rules/{id}/results` |
| 发布后作为正式口径 | `POST /publish`，同键旧规则自动归档 |

### 5.2 默认值（`teacher_total.yaml`）

```yaml
defaults:
  weights:
    usual: 0.40
    formal: 0.40
    certificate: 0.20
  aggregation:
    usual: average
    formal: average
    certificate: best
  certificateLevelScores:
    excellent: 95
    good: 85
    pass: 70
    fail: 50
  missingPolicy: renormalize
  lines:
    excellent: 90
    good: 80
    pass: 60
```

### 5.3 计算公式

```text
平时得分 = 平时类测评的 (total_score / max_score) × 100
正式得分 = 正式类测评的 (total_score / max_score) × 100
证书得分 = certificateLevelScores[证书等级]

总评 = Σ(单项得分 × 权重) / 有数据项的权重和
```

- **统计对象**：规则所属班级下状态为 `active` 的学生。
- **成绩来源**：`Score.status = graded`；按试卷 `paperType` 区分 `practice`（平时）与 `formal`（正式）。
- **证书来源**：`Certificate.status = ready`，按 `Certificate.level` 映射；同一学生多张证书按配置聚合。
- **日期范围**：成绩按 `Score.created_at` 的日期、证书按 `issue_date`，落在 `start_date ~ end_date` 内。
- **聚合方式**：`average`（平均）、`latest`（最近一次）、`best`（最高）。
- **缺项策略**：
  - `renormalize`（默认）：缺项不进入分母。例如平时 80、正式 70、无证书：`(80×0.4 + 70×0.4) / 0.8 = 75`。
  - `zero`：缺项按 0 分计入。同上数据：`(32 + 28 + 0) / 1.0 = 60`。
- **等级判定**：总评 ≥ 优秀线为 `excellent`，≥ 良好线为 `good`，≥ 合格线为 `pass`，否则 `fail`。

计算示例（默认权重 0.4 / 0.4 / 0.2）：平时成绩 80、90（平均 85），正式 70，证书优秀（95）：

```text
85 × 0.4 + 70 × 0.4 + 95 × 0.2 = 34 + 28 + 19 = 81
```

## 10. 已知边界与后续建议

1. **规则库是通用基线**：依据文化和旅游部《社会艺术水平考级管理办法》的管理框架，参考主流考级机构 1-10 级大纲的共性要求整理，不是任何机构的官方大纲。上线前应由教研按实际选用机构校准 `weights`、`anchors`、`bandCutoffs`，并用不少于 30 份真实作品做盲评一致性分析。
2. **只规定“怎么评分”**：规则库不含各级曲目、题材、尺寸、工具等“考什么”的内容，这部分以考级机构大纲为准。
3. **总评不落库**：每次查询按当前规则实时计算，修改规则后重新查询得到新结果。如需“发布即冻结”，应在发布时另存结果快照表。
4. **统计范围**：只聚合 `graded` 成绩与 `ready` 证书；生成中/失败证书、未完成评分的答卷不计入。
5. **类别推断有限**：题干关键词只能覆盖常见表述；建议在题目 `answer._ruleContext` 中显式声明类别与级别，或在模型返回中给出合法 `category`。
6. **单个已发布规则**：同一教师、班级、学科、学期只能有一条已发布规则；需要并行口径时可使用不同 `term` 或先归档旧规则。
7. **证书等级口径**：默认按优秀/良好/合格/不合格四档折算；如机构证书等级不同，可通过 `certificateLevelScores` 调整映射值，或后续扩展等级枚举。
