# 发给：（后端 A）

模型B 出题服务接入所需材料都在这个文件夹。三件事：调 8002、题卡入库、图片地址与审核流转。

## 一、文件夹内容

| 文件 | 用途 |
|---|---|
| `模型B出题_对接说明.md` | 启动、接口、图题规则、字段增补、联调清单（主文档） |
| `题卡字段规范_v1_参考.md` | 旧题卡规范原文，只作字段对照；以主文档「字段增补」为准 |
| `openapi.json` | 机器可读接口定义，可导入 Apifox/Postman |
| `示例_请求与返回.json` | 真实返回样例（图题、文字题、批量），字段完整 |

## 二、接入四步

1. 部署：按 `README_部署.md`，启动 `uvicorn model_b_qgen.app:app --host 0.0.0.0 --port 8002`。权重（Qwen2.5-3B-Instruct 5.8G + qgen_lora_3b_v4 309M）我单独网盘给你，放 `<仓库根>/weights/`，不入 Git。首次生成要加载模型，约 1–2 分钟。
2. 对表：`GET /catalog` 的年级、单元、知识点是否和你们目录一致；不一致先告诉我，不要只改一边。
3. 调通：`POST /generate` 四个题型各来一道；再 `POST /generate_batch` 来一套 10–16 题。
4. 入库：新题 `review_status=pending`，人工审核后再转 `approved`；未审不进正式测评。

### 部署环境与调用

- 主系统按 `README_部署.md`：`cp repo/.env.example repo/.env` 后填数据库、Redis、MinIO；模型服务不走 Docker，单独起 8002。
- 建议 GPU 显存 ≥6GB、磁盘 ≥15GB；无 GPU 可设 `QGEN_LOAD_4BIT=0` 用 CPU，但单题很慢，不建议生产。
- 首次生成前先轮询 `/health`，`model_loaded=true` 再放流量。
- 生成接口服务内串行（有锁）：单题超时 ≥60 秒，批量 16 题 ≥180 秒；后端不要并发打满。
- 后端在 Docker 内时，8002 用 `host.docker.internal:8002` 访问。
- 主系统入库请用你们自己的主键；`card.id` 只作追溯，`raw_output` 不用存。

## 三、必须注意的五点

1. **`with_image`**：默认 `true`。`true` 时优先出图题，没同题型素材自动退回文字题，不会串题型；要纯文字题显式传 `false`。
2. **`resources.role`**：`question` 是题目配图，要存要展示；`reference` 是知识点映射的参考图，不是题干配图。入库时两个都存，但要带上 `role`。
3. **`source=image_template`**：图题卡的来源枚举，数据库枚举要允许它，或映射成 `self_instruct`；`fact_ids` 一并保存，方便人工溯源。
4. **图片 URL**：返回的 `url` 默认是 `/resources/...` 相对路径。用 `QGEN_RESOURCE_URL_BASE` 配成你们的媒体前缀（如 `/media/question_image`），并确保能访问。图片文件在 GitHub 包 `data/12_image_assets/`，按 `resources[].file` 同步到媒体库，或直接暴露 8002 的 `/resources`；前端不要硬编码地址。
5. **单元映射**：模型给的是 `unit_id`/`unit_name`（如 `g4-u1`「色彩表现」），题库是 `Course` + `Chapter` 两套 ID。同包 `课程章节映射_美术1-9年级.csv` 是 1–9 年级 36 个单元的对照，组卷和入库都按它建课程/章节；对不上先找我，不要两边各改。

## 四、判分边界

- `/generate`、`/generate_batch` 实时生成的题**没入库、没有库内 ID**，不能直接判分；要即时判分先入库，再拿入库后的题卡走你们判分。
- `/paper`、`/grade` 是服务自带的参考实现：如果你们用自建题库和判分，**只接 `/catalog` + `/generate*` 即可**，不必把组卷/判分搬过来。
- 服务自带的 `/grade` 里，解答题一律 `needs_manual=true`，不计分。

## 五、联调检查清单

- [ ] `/health` 返回 `status=ok`，`adapter` 指向 `qgen_lora_3b_v4`
- [ ] `/catalog` 与后端目录一致
- [ ] 四题型各 1 道，`ok=true`，答案/解析非空
- [ ] 图题：`resources` 有 `role=question`，图片 URL 能打开
- [ ] 文字题：不出现题目配图，`role=reference` 不进题干区
- [ ] 批量 10–16 题：题型数量符合请求，无重复题干
- [ ] 入库：`source=image_template` 不被枚举拒绝，`resources`/`fact_ids` 落表
- [ ] 判分：组卷题得分正确，解答题 `needs_manual=true`
- [ ] 审核：新题 `review_status=pending`

有对不上的先约联调，不要各自改口径。
