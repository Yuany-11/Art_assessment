# 美术出题题卡规范 v1

对齐后端 `backend/apps/qbank` 的 Question / QuestionOption 字段。生成结果先写成题卡 JSON，再由导出脚本转成后端 `POST /questions` 的请求体。

## 1. 题卡字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | 题卡唯一 ID，格式 `qgen-0001`；人工题为 `golden-0001` |
| subject | string | 是 | 固定 `art` |
| grade | int | 是 | 1–9 |
| unit_id | string | 是 | 来自 `catalog.json`，如 `g7-u3` |
| unit_name | string | 是 | 单元名称，与目录一致 |
| knowledge_point | string | 是 | 必须是该单元 `knowledge_points` 中的一个 |
| type | string | 是 | `single_choice` / `true_false` / `fill_blank` / `short_answer` |
| difficulty | int | 是 | 1–3；1 识记、2 理解应用、3 综合运用 |
| stem | string | 是 | 题干，1–5000 字 |
| options | array | 选择题必填 | `[{"key":"A","text":"..."}]`，单选固定 4 个，key 不重复 |
| answer | object | 是 | 见第 2 节 |
| analysis | string | 是 | 答案解析，不能为空 |
| score | number | 是 | 0.5–100；建议单选/判断/填空 5 分，解答 10 分 |
| scoringMode | string | 是 | 客观题 `auto`；解答题 `manual` 或 `ai` |
| source | string | 是 | `golden` / `public` / `self_instruct` |
| review_status | string | 是 | `pending` / `approved` / `rejected` |
| created_by | string | 是 | `human` 或 `model:<模型名>` |
| notes | string | 否 | 审核意见、来源链接、存疑点 |

## 2. answer 格式（后端强校验，错一个字段就 400）

- `single_choice`：`{"value": "B"}`，value 必须在 options 的 key 中
- `true_false`：`{"value": true}`，必须是布尔值，不能写 "对"
- `fill_blank`：`{"values": ["色相", "明度", "纯度"]}`，按空格顺序，不能为空串
- `short_answer`：`{"text": "参考答案……"}`，不能为空

## 3. 题型规则

- 选择：单选、4 个选项、1 个正确答案；干扰项必须是同学段学生容易混淆的概念，不能凑数。
- 判断：只出能明确判定真假的陈述，禁止“可能”“一般”这类模糊表述。
- 填空：一题 1–3 个空，答案唯一且短；不接受多种等价写法（如“红黄蓝”和“红、黄、蓝”）混用，统一在 analysis 里说明。
- 解答：问题要能按点给分，答案写 2–4 个得分点；7–9 年级可结合作品分析，但不能凭空编造作品细节。

## 4. 年级语言约束

- 1–2 年级：句子不超过 25 字，不用“构图”“明度”“笔触”等术语；多用“哪个”“是不是”。
- 3–4 年级：可引入对比色、主体、疏密；解释术语时要带一句大白话。
- 5–6 年级：可出现透视、明暗、色调；题干不超过 60 字。
- 7–9 年级：可用美术史、风格、形式语言；解答题题干不超过 120 字，必须指明从哪个角度作答。

## 5. 严禁项

- 不得出现教材/课本原文照抄的长段材料。
- 不得编造画家、作品、年代、收藏地；不确定就不出。
- 不得一题多解却只给一个答案。
- 不得重复题干；查重阈值：规范化后字符 3-gram Jaccard > 0.85 视为重复。
- 不得使用真人学生作品或未授权图片；v1 只出文本题。
